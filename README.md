## Report Structure

Each monthly report includes:

- **Pull Requests**: PRs I authored (merged, closed, and open), each with a short description.
- **Reviewed PRs**: PRs by others that I reviewed.
- **Other Contributions**: issues filed or claimed, discussions, and other community work.
